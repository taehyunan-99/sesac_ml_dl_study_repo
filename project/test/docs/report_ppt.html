02 / 08
Problem Definition

문제 정의

🏙️

배경

서울 부동산 시장의 가격 변동성이 커지면서, 아파트 거래금액에 영향을 미치는 요인을 데이터 기반으로 이해할 필요성이 높아졌습니다.
체감과 실제 데이터 사이의 괴리를 통계적으로 검증합니다.

🎯

분석 목적

서울 아파트 실거래 데이터(2020~2024, 22만 건)를 분석하여 거래금액에 영향을 미치는 핵심 요인을 통계적으로 파악하고,
각 요인의 실질적 영향력을 정량화합니다.

❓

핵심 질문

어떤 요인—지역(시군구), 면적(전용면적), 단지 규모(세대수), 건물 노후도(경과년수)—이 서울 아파트 거래금액에 얼마나 영향을 미치는가?

전용면적

대단지 = 강남권·신도시 입지 효과 반영 가능성.

Conclusion

결론

서울 아파트 거래금액은 시군구(지역)과 전용면적(면적)이 가격 분산의 약 76%를 설명하며, 이 두 요인이 가격 결정의 핵심 축입니다.

⚠️ 한계점

  • 비모수 검정(순위 기반) — 그룹 간 평균 차이 별도 확인 필요
  • 거래금액 우편향 분포 — 로그 변환 후 재분석 검토
  • 시군구 효과가 다른 변수 효과를 혼재시킬 가능성 (교란 변수)
  • 대표본(n=215,144) 검정력 과잉 — 효과 크기 병행 해석 필수

🔮 후속 분석

  • 시군구별 거래금액 박스플롯 시각화
  • 전용면적 ↔ 거래금액 산점도 (비선형 확인)
  • 다중회귀분석 — 시군구·전용면적·세대수 독립적 영향력 분리
  • 거래금액 로그 변환 후 모수 검정 재분석
