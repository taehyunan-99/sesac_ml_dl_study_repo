## 5. 변수 간 관계

### 강한 상관관계 (|r| > 0.7)

| 변수 1 | 변수 2 | 상관계수 | 해석 |
|--------|--------|---------|------|
| 세대수 | 주차대수 | 0.95 | 거의 동일 정보 → 모델링 시 하나 제거 또는 VIF 확인 |
| 경과년수 | 입주년도 | -0.99 | 수학적 파생 관계 (경과년수 = 계약년도 - 입주년도) → 반드시 하나 제거 |

| 변수 1 | 변수 2 | 상관계수 | 해석 |

| 전용면적 | 거래금액 | 약 0.5~0.6 | 면적↑ 가격↑ 경향, 지역별 편차 커서 비선형 가능성 |
