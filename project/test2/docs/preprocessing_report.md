# 전처리 보고서

## 1. 전처리 개요

### 파이프라인 정보
| 항목 | 값 |
|------|-----|
| 원본 데이터 | `UniversalBank.csv` |
| 전처리 노트북 | `preprocessing.ipynb` |
| 저장 파일 | `cleaned/UniversalBank_cleaned.csv` |
| EDA 보고서 참조 | `docs/eda_report.md` |

### 전처리 전후 비교
| 항목 | 전처리 전 | 전처리 후 | 변화 |
|------|----------|----------|------|
| 행 수 | 5,000행 | 5,000행 | 변화 없음 |
| 열 수 | 10열 | 10열 | ID 제거(-1) + HasMortgage 추가(+1) |
| 결측값 | 0건 | 0건 | 없음 |
| 중복 행 | 0행 | 0행 | 없음 |

### 전처리 전략 요약
> 5,000행 × 10열 은행 고객 데이터로, 결측값·중복이 없어 품질은 양호했다.
> EDA에서 발견된 Experience 음수값(52건), Mortgage 분포 편향, 범주형 인코딩 필요가 주요 이슈였으며,
> 행 삭제 없이 이상값 대체·피처 분리·인코딩 중심으로 전처리를 진행했다.

---

## 2. 전처리 순서 및 근거

| 순서 | 단계 | 이유 |
|------|------|------|
| 1 | ID 컬럼 제거 | 불필요 컬럼 먼저 제거하여 이후 처리 대상 축소 |
| 2 | Experience 음수값 대체 | 이상값이 통계량을 왜곡하기 전에 처리 |
| 3 | Mortgage 피처 분리 | 분포 특성 파악 후 피처 엔지니어링 |
| 4 | 범주형 인코딩 | 마지막에 수행하여 수치 연산과 혼선 방지 |

---

## 3. 처리 내역

### 컬럼 제거
| 컬럼명 | 제거 사유 | 근거 |
|--------|----------|------|
| ID | 고객 식별자(인덱스) — 분석 및 모델링에 무관 | 순번 변수, 예측력 없음 |

### 이상치 처리
| 변수 | 이상치 내용 | 건수 (비율) | 처리 방법 | 판단 근거 |
|------|-----------|------------|----------|----------|
| Experience | min = -3 (음수 경력) | 52건 (1.04%) | Age 기반 대체 (offset=25.0) | EDA에서 Age ≈ Experience + 25 관계 확인. 음수 경력은 입력 오류로 판단. 행 삭제 대신 대체 선택 — 거래 자체는 유효하고 다른 변수에는 이상 없음. 대체 후 min=0 확인. |

**유지한 이상치 (의도적):**
| 변수 | 내용 | 유지 사유 |
|------|------|----------|
| Income | max=224 (평균 73.8 대비 큰 값) | 고소득 고객은 실제 존재하는 도메인 특성. IQR 기준 이상치지만 비즈니스상 정상 범위. |
| CCAvg | max=10.0 (평균 1.9 대비 큰 값) | 고소득 고객의 높은 카드 지출로 해석 가능. Income과 양의 상관이 있어 도메인상 타당. |
| Mortgage | max=635 (보유자 평균 183.7) | 고가 모기지는 실제 존재. 보유자 기준 분포(75~635)로 볼 때 정상 범위. |

### 피처 엔지니어링
| 컬럼 | 처리 내용 | 판단 근거 |
|------|----------|----------|
| Mortgage → HasMortgage 추가 | 모기지 보유 여부 이진 변수 신규 생성 (0: 3,462건 / 1: 1,538건) | Mortgage 중위수=0, 약 69.2%가 0 — 보유 여부 자체가 독립적인 정보를 가짐. 기존 Mortgage 금액 컬럼은 유지하여 보유자 금액 분석 가능하게 함. |

### 범주형 인코딩
| 컬럼 | 변환 전 | 변환 후 | 사유 |
|------|---------|---------|------|
| CDAccount | object (Yes/No) | int64 (1/0) | 이진 변수로 레이블 인코딩 적합. Yes=302건(6.0%), No=4,698건(94.0%) |
| PLoan | object (Yes/No) | int64 (1/0) | 타겟 변수 후보. Yes=480건(9.6%), No=4,520건(90.4%). 모델링 시 불균형 처리 필요. |

## 4. 전처리 후 데이터 상태

### 최종 컬럼 목록 (10열)
| 컬럼명 | dtype | 설명 |
|--------|-------|------|
| Age | int64 | 고객 나이 |
| Experience | int64 | 경력 연수 (음수 대체 완료) |
| Income | int64 | 연소득 (단위: $K) |
| Family | int64 | 가족 수 (1~4, 이산형) |
| CCAvg | float64 | 월평균 신용카드 지출 (단위: $K) |
| Education | int64 | 교육 수준 (1~3, 이산형) |
| CDAccount | int64 | CD 계좌 보유 여부 (1=보유) |
| Mortgage | int64 | 모기지 금액 (0=미보유) |
| PLoan | int64 | 개인 대출 여부 (1=수락, 타겟 후보) |
| HasMortgage | int64 | 모기지 보유 여부 이진 변수 (신규 생성) |

### 데이터 품질
| 항목 | 상태 | 상세 |
|------|------|------|
| 결측값 | 🟢 0건 | 원본부터 결측 없음 |
| 이상치 | 🟡 잔존 | Income·CCAvg·Mortgage 우편향 — 도메인 특성상 정상, 분석 시 로그 변환 검토 |
| 타입 정합성 | 🟢 적합 | 모든 컬럼 수치형으로 변환 완료 |
| 중복 | 🟢 0건 | 원본부터 중복 없음 |

### 잔존 리스크 및 주의사항
| 항목 | 내용 | 영향 | 권장 대응 |
|------|------|------|----------|
| PLoan 불균형 | Yes 9.6% (480건) | 분류 모델링 시 정확도 왜곡 가능 | SMOTE 오버샘플링 또는 class_weight 조정 |
| Age ↔ Experience 다중공선성 | 강한 양의 상관 (Age ≈ Experience + 25) | 선형 모델에서 VIF 높아질 수 있음 | VIF 검정 후 하나 제거 또는 PCA |
| Mortgage + HasMortgage 중복 정보 | 동일 정보 두 컬럼 존재 | 모델에 따라 불필요한 중복 | 모델링 목적에 따라 하나만 사용 |
